# rnctl-cli

One mission control for React Native. Boot devices, run Metro, and stream unified native + JS logs without Xcode or Android Studio.

```sh
npx rnctl-cli
```

This installs the `rnctl` and `rnc` commands on your PATH. Run `npx rnctl-cli --help` for available commands.

Part of [rnctl](https://github.com/bittu/rnctl).
